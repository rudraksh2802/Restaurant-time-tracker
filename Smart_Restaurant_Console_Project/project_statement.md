# Project Statement

## Problem

Customers usually know a restaurant's location, but not its current crowd or queue. A nearby restaurant may have a long wait while a farther restaurant may have seats available.

## Objective

Build a simple Python system that records occupancy and queue size, estimates waiting time, and combines that with travel time.

## Scope

The current version supports one restaurant and uses console input. Automatic camera/sensor detection is a future enhancement.

## Target Users

- Customers
- Restaurant staff
- Restaurant management

## Expected Outcome

The system should present clear information about occupancy, available seats, queue size and estimated waiting time.
